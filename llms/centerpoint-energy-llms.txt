# CenterPoint Energy

> CenterPoint Energy (NYSE: CNP) is a US energy delivery company providing electric transmission and
> distribution, natural gas distribution and energy services across Texas, Indiana, Minnesota, Ohio and
> Louisiana. It runs no public developer program and publishes no OpenAPI, GraphQL, AsyncAPI, MCP server
> or A2A agent card. Its machine-readable surfaces are business-to-business and regulator-driven, reachable
> only after registration and a signed agreement.

Generated by the API Evangelist enrichment pipeline on 2026-09-05 from artifacts in this repository and
from provider documents fetched at HTTP 200 on that date. CenterPoint Energy does not publish an llms.txt
of its own — https://www.centerpointenergy.com/llms.txt returned 404 on 2026-09-05. Nothing below is
inferred; every claim traces to a document listed under Sources.

## What an agent can and cannot do here

- There is no callable public API. Nothing on this provider can be invoked with an API key.
- Meter data for CenterPoint Energy electric customers is reached through Smart Meter Texas, a platform
  jointly owned and funded by the four Texas TDSPs (CenterPoint Energy Houston Electric, Oncor, AEP Texas
  and TNMP). The contract is Smart Meter Texas's, not CenterPoint's alone.
- Reaching it requires an SMT entity account, a signed API SSL certificate matching your own domain,
  HTTP Basic credentials issued per DUNS, mutual TLS on every call, and an executed Energy Data Sharing
  Agreement with the customer whose meter you are reading. None of that is self-service.
- The contract is a 185-page PDF. There is no machine-readable description of it anywhere.

## APIs

- [Usage History via Smart Meter Texas Data Access API](https://www.smartmetertexas.com/): REST and SOAP
  at https://services.smartmetertexas.net (UAT https://uatservices.smartmetertexas.net). Functions:
  15-Minute Interval Data, Daily Register Reads, Monthly Billing Reads, Green Button, Meter Attributes,
  Premise Attributes, On-Demand Read, On-Demand Read Status, Report Status, New Subscription,
  Unsubscribe/Cancel Subscription, List Subscriptions, New Energy Data Sharing Agreement, List ESIIDs per
  Agreement, Terminate Agreement, Agreement Status. JSON request and response, except Green Button which
  returns NAESB ESPI XML.
- [Green Button Connect My Data](https://www.smartmetertexas.com/): the /greenbutton/ resource on the same
  interface, returning 15-minute interval, daily register or monthly billing data for one ESI ID in NAESB
  REQ.21 ESPI XML. Synchronous.

## Standards this provider actually speaks

- NAESB REQ.21 ESPI / Green Button — implemented as a callable endpoint, not a claim.
- ANSI X12 EDI via ERCOT TxSET, transaction set 810_02 (TDSP to Competitive Retailer invoice). CenterPoint
  publishes the EDI transaction names, ESI ID format and SAC04 codes retailers invoice against.

## Runtime semantics an agent should know

- Auth: mutual TLS (TLS 1.0-1.2 per the guide) plus HTTP Basic. No OAuth, no OIDC, no API keys.
- Errors: vendor JSON, {"error":"..."} or errorCode/errorMessage. Not RFC 9457. Documented codes:
  200, 400, 401, 403, 500. No 429 is defined.
- Rate limit: On-Demand Reads are capped at 3,000 per day per TDU — a ceiling shared across every caller
  on CenterPoint's network, not a per-key allowance. No RateLimit-* or Retry-After headers exist, so this
  ceiling is invisible at runtime.
- Idempotency: none. A retried New Subscription must be assumed to create a second subscription.
- Reversibility: subscriptions and data sharing agreements each have a documented inverse
  (UnSubscription, Terminate Agreement). No window is stated for either. An On-Demand Read triggers a
  physical meter read and cannot be undone.
- Pagination: none. Scope is bounded by ESI ID list and date range; bulk results arrive through an
  asynchronous report flow (submit, poll Report Status, collect).

## Corrections

An earlier profile of this company credited it with a "Centerpoint Connect Services API" at
api-portal.centerpointconnect.io. That developer portal belongs to Centerpoint Connect, an unrelated
commercial roofing CRM company at centerpointconnect.com, and has been removed from this record.
